# Güneş Coin Website — Rebrand v1

Bu paket GDN Coin web sitesinin Güneş Coin marka dönüşümüdür.

Önemli:
- Mevcut Sepolia kontratı eski GDN test kontratı olarak açıkça etiketlenmiştir.
- Yeni Güneş Coin kontratı deploy edilmeden site onu varmış gibi göstermemektedir.
- Eski GDN Whitepaper dosyası paketten çıkarılmıştır; yeni Whitepaper güncelleme aşamasında gösterilir.
- GitHub repository bağlantısı şimdilik mevcut GDN-Coin/GDN-Coin deposuna gider.
- gdncoin.io alan adı değiştirilmemiştir; yeni domain seçimi daha sonra yapılabilir.
- Token ticker/sembolü bu sürümde özellikle belirlenmemiştir.
