## Token Distribution

The total supply of Gunes Coin is permanently fixed at:

**1,000,000,000 GUNES**

Initial distribution:

- **950,000,000 GUNES (95%)** — Treasury
- **50,000,000 GUNES (5%)** — Charity Reserve

The smart contract does not contain an additional minting mechanism.

---

## Charity Reserve

5% of the total GUNES supply is allocated to a dedicated Charity Reserve.

The purpose of this reserve is to support future transparent charitable and social-impact initiatives as the ecosystem develops.

Gunes Coin does **not** deduct a charity fee from user transfers.

If a user transfers **100 GUNES**, the recipient receives **100 GUNES**, excluding the blockchain network gas cost paid separately by the sender.

## Smart Contract

The Gunes Coin smart contract is built with Solidity and OpenZeppelin contracts.

Key features include:

- ERC-20 compatibility
- Fixed supply
- ERC20Burnable
- ERC20Pausable
- Ownable2Step
- Emergency pause functionality
- Two-step ownership transfer
- No transfer tax
- No additional minting
- Dedicated Treasury allocation
- Dedicated Charity Reserve allocation

The current Gunes Coin smart contract has been successfully deployed and source-code verified on the Ethereum Sepolia Testnet.
