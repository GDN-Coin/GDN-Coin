# GDN Coin Website v4 Final

This package contains the final Website v4 design and official logo asset set.

## Upload to the GitHub repository root

Replace or add:

- `index.html`
- `styles.css`
- `script.js`
- `favicon.svg`
- `GDN_Coin_Whitepaper_v1.0_Beta.pdf`
- the complete `assets` folder

## Official logo assets

- `assets/gdn-mark.svg` — primary vector mark
- `assets/gdn-logo-horizontal.svg` — horizontal brand lockup
- `assets/gdn-app-icon-512.png` — app icon
- `assets/gdn-social-icon-1024.png` — social profile icon

## Notes

- English is the default language; Turkish is available through the TR/EN switch.
- The displayed contract is the verified Ethereum Sepolia testnet deployment.
- Mainnet launch is not represented as completed.
